# Smart College Complaint Analyzer

## Project Overview
Smart College Complaint Analyzer is an AI-based web application that automatically analyzes and categorizes student complaints using Machine Learning.

## Problem Statement
Colleges receive different types of student complaints. Manually sorting these complaints takes time. This project helps categorize complaints automatically.

## Technologies Used
- Python
- Machine Learning
- Scikit-learn
- Pandas
- Streamlit
- Matplotlib

## Categories
- Technology
- Transport
- Infrastructure
- Academics
- Canteen

## Features
- Automatic complaint classification
- AI-based category prediction
- Admin dashboard
- Category-wise complaint chart
- Complaint status management
- Search and filter complaints
- Excel download

## Machine Learning Algorithm
- TF-IDF Vectorization
- Multinomial Naive Bayes

## How to Run

1. Install the required libraries:

   `pip install -r requirements.txt`

2. Train the model:

   `python train_model.py`

3. Run the application:

   `streamlit run app.py`
